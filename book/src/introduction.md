# 介绍

**neural-resampler** 是一个通用神经重采样器引擎，用 **纯 Rust + ONNX** 重写了 HiFiSampler。

传统 UTAU 声库由两部分组成：录音样本（WAV）和每个样本的切分参数（`oto.ini`）。
负责变调、变时长、把碎片拼成歌声的，是 resampler 引擎。本项目的目标只有一个：
**只替换这个引擎，其余一概不动**。

## 设计取舍

| 维度 | 说明 |
| --- | --- |
| 声库兼容 | WAV 与 `oto.ini` 完全不动，原样沿用 |
| 声码器 | PC-NSF-HiFiGAN（NSF 架构，F0 条件化） |
| F0 提取 | FCPE（ONNX，16kHz），可回退到内置 DSP |
| 依赖 | 无 Python 运行时，单二进制部署 |
| 宿主兼容 | OpenUtau / 原生 UTAU，协议层可扩展 |

## 变调与变时长是怎么做到的

神经方案的巧妙之处在于把两件事**解耦**了：

* **变调** —— 直接改 F0 曲线。声码器以 F0 为条件，给定不同的 F0 就得到不同音高，
  不需要对波形做重采样，因此不会有传统重采样的金属声。
* **变时长** —— 对 Mel 频谱做时序拉伸/循环拼接。改的是帧数，与音高无关。

这意味着一个样本可以被拉伸到任意长度、唱到任意音高，而两者互不干扰。

## 处理流程

```
输入 WAV
   │
   ├─ Mel 分析（44.1kHz / 2048 FFT / 帧移 128）
   │
   ├─ F0 提取（FCPE，16kHz）  ──┐
   │                             ├─→ 按乐谱调整 F0
   ├─ 乐谱：音名 + pitchBend ────┘
   │
   ├─ Mel 时序拉伸到目标帧数
   │
   ├─ PC-NSF-HiFiGAN 声码器（Mel + F0 → 波形）
   │
   └─ 后处理（响度归一化、限幅、淡入淡出）→ 输出 WAV
```

## 什么时候适合用它

**适合**：想让传统声库获得更自然的音质；需要在无 Python 环境的机器上部署；
希望有一份可读、可改、可嵌入其他工具的 Rust 实现。

**不适合**：期待它凭空生成不存在的音素（它仍是拼接合成，只是拼接得更自然）；
需要 GPU 加速但又不愿意装 CUDA/DirectML（默认走 CPU，可用但慢）。
