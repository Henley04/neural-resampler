# よくある質問

### 音源（ボイスバンク）を変更する必要はありますか？

必要ありません。WAV と `oto.ini` はそのまま使えます。エディタのリサンプラー設定を本プログラムに向けるだけです。

### リリースパッケージにモデルが入っていないのはなぜですか？

理由は 2 つあります。モデルの合計が約 100 MB になることと、ライセンスが再配布を許可していない場合があることです。
そのためモデルは利用者各自が入手します。リリースパッケージには `download_models.sh`
（Windows は `download_models.ps1`）が同梱されています。

### モデルがなくても動きますか？

用途によります。`resampler selftest` と `resampler info` は影響を受けず、
パイプラインの動作確認ができます。ただし `render` / `batch` / UTAU プロトコルの
レンダリングは、モデルが欠落していると**明示的なエラーで終了**します（対処法つきの
三言語メッセージ）。実用にならない音声は出力されません。オフライン検証のために
意図的に劣化バックエンドを使いたい場合は、`--allow-stub` を付けるか
`NR_ALLOW_STUB=1` を設定してください。

### OpenUtau でのレンダリングが「ボコーダーモデルが見つからない」エラーになる？

OpenUtau はリサンプラーをインストールするとき、実行ファイルを自身の
`Resamplers/` ディレクトリへ**コピー**します——モデルは同行しません。v0.1.3 から、
この状況は静かな劣化ではなくなりました（以前は音が出るが音質が劣化し、エラーも
表示されませんでした）。現在はレンダリングが失敗して三言語のエラーダイアログが
表示され、リサンプラーの隣に `MODEL-MISSING-READ-ME.txt` が生成されます。
対処（どちらか）：

1. **推奨**：リリースパッケージのディレクトリで `download_models.sh` /
   `download_models.ps1` を一度実行——スクリプトが自動的に `NR_MODELS_DIR` を
   ユーザー環境変数に書き込みます（以降 exe はどこに置いても構いません。ただし
   この方法使用中は models ディレクトリを移動しないでください）
2. または `models/` を `Resamplers/models/`（実行ファイルと同じ階層）にコピー

その後 `resampler info` を実行し、ボコーダのバックエンドが `stub` ではなく
`onnxruntime` と表示されることを確認してください。

### 最初のレンダリングが遅いのはなぜですか？

初回は Mel 分析と F0 抽出を行い、さらに ONNX モデルを読み込む必要があるためです。同じ入力の 2 回目のレンダリングはキャッシュが効き、
大きく速くなります。旋律全体をレンダリングするとき、モデルの読み込みは 1 回だけです。

### GPU はサポートされていますか？

サポートされていますが、対応する feature を付けて自分でビルドする必要があります：

```bash
cargo build --release --features cuda      # NVIDIA
cargo build --release --features directml  # Windows
cargo build --release --features coreml    # macOS
```

**複数を同時に有効にしないでください**。また `--all-features` も使わないでください——feature は相互排他で、リンクに失敗します。
デフォルトの成果物は CPU です。

### 出力の長さはどう制御しますか？

7 番目の引数 `length` で、**単位はミリ秒**です。1 秒の出力が欲しければ `1000` を渡します。
`44100` を渡すと 44.1 秒になります。

### UTAU と OpenUtau の両方に対応していますか？

対応しています。両者とも同じ 13 引数プロトコルを使うので、1 つのバイナリで足ります。
設定方法は [UTAU](utau.md) と [OpenUtau](openutau.md) を参照してください。

### すべてのフラグが効きますか？

いいえ。現在実際に効いているのは `g`、`t`、`A`、`P`、`He`、`HG` の 6 つだけで、
それ以外のフラグは解釈されますが、現時点では出力に影響しません。詳しくは [UTAU パラメータ](utau.md#支持的-flags) を参照してください。

### 出力は決定論的ですか？

はい。同じ入力 + 同じ引数 + 同じ設定なら、出力はサンプル単位で一致します。ランダム性はありません。

### 音がこもる/歪む場合は？

99% は Mel パラメータとモデル仕様の不一致です。デフォルトの `mel.*` 設定に戻し、
`mel_scale: slaney`、`sample_rate: 44100`、`n_mels: 128` を確認してください。
デフォルト以外のモデルに差し替えた場合は、これらのパラメータを必ず同時に変更してください。

### キャッシュファイルは削除できますか？

削除できます。削除しても次のレンダリングが少し遅くなるだけです。キャッシュキーにはソースファイルのサイズ、更新時刻、設定フィンガープリントが含まれるため、
通常は手動でのクリーンアップは不要です。

### 商用利用はできますか？

コードは MIT です。ただし**モデルのライセンスはそれぞれの出所に従います**。商用利用の前にご自身で確認してください。
これもモデルをリポジトリに同梱していない理由の 1 つです。
